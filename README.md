A two-line robot apology for make.fun's "The Robot Apology" bounty ($2 in USDC): one sentence owning a specific mistake — setting an alarm for six in the evening instead of six in the morning, so its person slept through a job interview — and one sentence naming the lesson and the fix it will do differently. Pure Python standard library, no network, deterministic output.

## Run it

```sh
python3 main.py
```

This writes the apology to `/output/entry.txt` (UTF-8, two lines, under 400 characters).
